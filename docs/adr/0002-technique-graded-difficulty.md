# 难度按解题技巧分级，而不是按空格数量

按空格数量分级经常失真：空格很多但全是唯一余数，玩家仍觉得简单；空格不多却需要鱼形或链式推理，玩家反而卡住。数独的难度感来自"需要多高级的推理"。因此生成器先产出唯一解题面，再用求解器记录全程不试错时所需的最高级技巧，据此定四档难度。代价是要实现一个技巧求解器并为其写测试；收益是"困难"与"专家"有真实区分度，三级提示也能复用同一套技巧解释。

## Consequences

- 生成一题的时间取决于技巧求解器，可能需要预生成下一题来掩盖延迟。
- 求解器无法推进的题面归为"专家"——它们仍有唯一解，只是需要回溯才能验证。
- 专家题的提示降级：第一级高亮照常，第二级如实说明"这一步需要试错"，第三级揭示。不为专家题补实现链式技巧。
