# 轻点数字记笔记，长按数字填答案

数独的常规输入是"先选格、再点数字填数"，笔记要么靠一个模式开关，要么靠第二个手势。这里反过来：轻点是默认动作（记/删候选），长按 450ms 才是填答案。理由是这位玩家的大部分落子发生在候选数收敛之后——记笔记是高频动作，填数是低频但需要确认的动作；长按天然把误触挡在外面。

## Considered Options

- **笔记模式开关**：需要额外状态与一个工具按钮，玩家经常忘记自己处在哪个模式。
- **先选数字再连点格子**：适合批量填同一个数字，但与"轻点记笔记"冲突。
- **长按弹出菜单**：多一步，且打断心流。

## Consequences

- 长按必须吞掉松手时的那一次 click，否则一次长按会同时填数并记一笔笔记。实现用一次性标志、在下一次 pointerdown 复位，而不是时间窗口，避免误吞下一个手势。
- 长按也复用到擦除：轻点擦除清当前格，长按 450ms 清空整盘候选；两者共用同一个一次性 click 抑制。
- 被同行、同列、同宫占用的数字在键盘上划掉，但只约束"记笔记"；长按仍然可以填入（并标红）。答案由玩家决定，候选由规则约束。
- 发现性差，界面必须常驻一行"轻点记笔记 · 长按填答案"，正式实现还需要首次引导。
- 工具行不再需要"笔记"按钮，改成 撤销 / 擦除 / 提示 / 暂停。
