# 零框架：原生 TypeScript + Vite

数独的界面是 81 个格子、一个数字键盘和几层面板，状态集中在单个对局对象上，没有路由、没有复杂组件树、没有跨页共享状态。引入 React 或 Svelte 会带来包体、升级与心智负担，却换不来明显收益。因此用原生 TypeScript 直接操作 DOM，逻辑层与渲染层分离，引擎不依赖浏览器。

## Considered Options

- **React + Vite**：生态成熟，但为了一个静态棋盘引入运行时与协调器。
- **Svelte + Vite**：界面代码更短，但依赖编译器，且对这个规模的项目优势不明显。

## Consequences

- 复杂交互（键盘、手势、动画）需要手写，但本项目没有复杂交互。
- 若界面规模意外增长，渲染层可整体替换，引擎与存档格式不受影响。
